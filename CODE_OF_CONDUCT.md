# AIONEX community code of conduct

## Our standard

Project participation should be respectful, technically constructive, and safe
for people of different backgrounds and experience levels. AIONEX expects
participants to:

- discuss ideas and code rather than attacking people;
- give actionable feedback with relevant evidence;
- respect privacy, consent, attribution, and intellectual-property rights;
- use inclusive language and accommodate good-faith questions;
- disclose conflicts of interest that affect a contribution; and
- de-escalate disagreements and follow maintainer decisions on project scope.

## Unacceptable behavior

Harassment, discrimination, threats, stalking, sexualized conduct, doxxing,
deliberate intimidation, sustained disruption, impersonation, publishing
another person's private information, or knowingly submitting malicious code is
not acceptable. Spam, deceptive promotion, fabricated claims, and attempts to
obtain credentials or private conversations are also prohibited.

## Scope

This code applies in repository issues, pull requests, reviews, discussions,
security coordination, and other spaces where someone is representing this
project or AIONEX.

## Reporting and enforcement

Use the repository host's private moderation or abuse-reporting feature when
available. If no private channel is available, open a minimal public issue that
requests maintainer follow-up without naming affected people or revealing
sensitive details. Security vulnerabilities belong in the process described by
[SECURITY.md](SECURITY.md).

AIONEX may remove content, request a correction, issue a warning, limit
participation, or permanently exclude a participant based on the nature and
pattern of conduct. Reports will be considered in context and shared only as
needed for moderation, subject to platform and legal requirements. No specific
outcome or response time is guaranteed.
